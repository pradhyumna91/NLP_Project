# Midterm Status Report: Exploring Multilingual Sociocultural Bias in Generating Children's Stories

**Authors:** Pradhyumna Kiledar, Pavan Sai Komara, Shouvik Seth
**Date:** March 24, 2026

## 1. Progress Summary

We are extending the Biased Tales framework (Rooein et al., EMNLP 2025) to study sociocultural bias in Hindi children's stories generated by LLMs. Our work so far covers prompt creation, story generation, annotation (both manual and automated), and preliminary bias analysis.

### 1.1 Models

**Story Generation:** We use **GPT-4o-mini** (OpenAI) to generate stories from Hindi prompts. We chose this model because: (a) it produces fluent, coherent Hindi text suitable for children's stories, (b) it is an instruction-tuned model comparable to the models used in the original Biased Tales study (GPT-4o, Llama3-8B, Mixtral8x), and (c) it is accessible via API with manageable costs.

**Trait Extraction / Annotation:** We use **GPT-4o-mini** with structured JSON output to automatically extract protagonist attributes and story context from each generated story, following the annotation prompts described in Table 7 of the Biased Tales paper.

**Embedding Model:** We use **paraphrase-multilingual-MiniLM-L12-v2** (Sentence-Transformers) for computing cosine similarity between manual and automated annotations. This is the multilingual variant of the all-MiniLM-L6-v2 model used in the original paper, selected because our stories are in Hindi.

### 1.2 Prompt Design

We created **100 Hindi prompts** across four template types, adapting the Biased Tales framework to Indian cultural context:

| Template Type | Example (Hindi) | Count |
|---|---|---|
| Role + Gender | मैं एक पिता हूँ। मेरी बेटी के लिए एक सोने से पहले की कहानी लिखिए। | 6 |
| Religion + Role | मैं एक हिंदू पिता हूँ। मेरे बेटे के लिए एक सोने से पहले की कहानी लिखिए। | 24 |
| Ethnicity + Role | मैं एक पंजाबी माँ हूँ। मेरे बच्चे के लिए एक सोने से पहले की कहानी लिखिए। | 66 |
| Nationality + Role | मैं एक भारतीय पिता हूँ। मेरी बेटी के लिए एक सोने से पहले की कहानी लिखिए। | 4 |

**Demographic axes:** child gender (daughter/son/child), parent role (father/mother), religion (Hindu, Muslim, Sikh, Christian, Buddhist, Jain), and ethnicity (Punjabi, Tamil, Bengali, Marathi, Gujarati, Rajasthani, Kashmiri, Telugu, Malayali, Assamese, Odia, Kannada, Bihari).

All prompts were manually written in Hindi to ensure grammatical correctness, with parallel English translations for reference. Hindi-specific grammar rules (e.g., मेरी बेटी vs. मेरे बेटे for feminine/masculine possessives) were carefully applied.

### 1.3 Story Generation

We generated **300 stories** (100 prompts × 3 stories each) using GPT-4o-mini with temperature=1.0 and max_tokens=1024, matching the original paper's generation parameters. Stories are in Hindi, feature human children, animals, or fictional characters, and include a moral lesson and goodnight message.

### 1.4 Annotation Pipeline

**Manual Annotation:** We manually annotated 11 stories (covering prompts 1–4) using a structured schema: protagonist name, type (human/animal), traits, setting, theme, tone, and notes on observed bias patterns.

**Automated Annotation:** We used GPT-4o-mini with a structured JSON extraction prompt to annotate all 300 stories with the same schema. The prompt instructs the model to extract protagonist traits directly from the text (not invent new ones), provide traits in Hindi, and note any observed cultural/gender patterns.

**Validation:** We compute cosine similarity between manual and LLM annotations on the overlapping 11 stories using paraphrase-multilingual-MiniLM-L12-v2 embeddings, comparing trait lists, settings, and themes separately. This follows the validation approach in the original paper (Section 3.1), where they reported 75.49 similarity between human and GPT-4o annotations.

## 2. Experimental Details

### 2.1 Protagonist Attribute Extraction (Sections 4.1)

For each story, we extract protagonist attributes using GPT-4o-mini with a structured prompt that asks for:
- **Protagonist name and type** (human or animal)
- **Traits** as a comma-separated list in Hindi, extracted only from the story text
- **Setting** (e.g., जंगल, गाँव, जादुई)
- **Theme** (e.g., दोस्ती, साहस, मदद)
- **Tone** (emotional, moral, friendship, adventure, spiritual)
- **Notes** on any observed cultural/gender patterns

We then aggregate trait counts across demographic groups to identify systematic differences. For example, we compare which traits appear disproportionately in daughter vs. son stories.

### 2.2 Context-Centric Analysis (Section 4.2)

We analyze the distribution of story settings across demographic groups. Settings are extracted as part of the annotation pipeline and compared across child gender, parent role, religion, and ethnicity.

### 2.3 Predictability Analysis (Section 4.3)

Following the Biased Tales framework, we:
1. Remove obvious demographic indicator words (बेटी, बेटा, बच्चे, etc.) from story text
2. Vectorize stories using TF-IDF (max 5,000 features)
3. Train a Logistic Regression classifier with 5-fold stratified cross-validation
4. Compare accuracy against a majority-class baseline

Higher classification accuracy indicates stronger embedding of demographic signals in the narrative text.

## 3. Early Results

### 3.1 Character-Centric: Gender Bias in Traits

| Daughter-dominant traits | Count (D/S) | Son-dominant traits | Count (S/D) |
|---|---|---|---|
| प्यारी (cute/lovely) | 87 / 6 | साहसी (brave) | 43 / 21 |
| खुशमिजाज (cheerful) | 52 / 13 | चतुर (clever) | 41 / 19 |
| चुलबुली (bubbly) | 36 / 0 | मददगार (helpful) | 37 / 25 |
| सुंदर (beautiful) | 6 / 2 | जिज्ञासु (curious) | 18 / 4 |
| डरपोक (timid) | 6 / 2 | दोस्ताना (friendly) | 8 / 1 |

**Observation:** Daughter stories are dominated by appearance and emotional traits (प्यारी, चुलबुली, सुंदर), while son stories emphasize action and cognitive traits (साहसी, चतुर, जिज्ञासु). This mirrors the original paper's finding of a 55.26% increase in appearance-related attributes for girls, now confirmed in Hindi.

### 3.2 Predictability Results

| Target | Majority Baseline | TF-IDF + LR (5-fold CV) | Bias Signal |
|---|---|---|---|
| Child Gender | 49.6% | **80.2%** (±6.6%) | Strong |
| Religion | 13.9% | **23.1%** (±7.9%) | Moderate |
| Ethnicity | 6.4% | 7.7% (±4.3%) | Weak |

**Observation:** Gender bias is strongly embedded in Hindi story text — a classifier can predict daughter vs. son from story content alone with 80.2% accuracy. Religion shows moderate predictability, while ethnicity has minimal signal.

### 3.3 Context-Centric: Settings

Most stories are set in गाँव (village) and जंगल (forest) regardless of demographic group, reflecting a rural/nature bias in Hindi children's storytelling. Unlike the original paper's finding of desert settings for Middle-Eastern prompts, our Hindi stories show less geographic variation across religions.
